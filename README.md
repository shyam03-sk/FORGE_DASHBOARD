# FORGE Manufacturing Intelligence Dashboard

## Publish with GitHub Pages

1. Create a **public** GitHub repository (for example, `forge-dashboard`).
2. Upload `index.html` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for deployment. Your site URL will look like:
   `https://YOUR-USERNAME.github.io/forge-dashboard/`

This dashboard includes its Plotly JavaScript library inline and has no external script or CSS file references detected in the HTML. It should therefore be suitable for static hosting, provided the dashboard works correctly in your browser.

Before publishing, check that the data shown in the dashboard is safe to make public.
